# AI Career Accelerator Campaign System

## Project Overview

The **AI Career Accelerator Campaign System** is an AI-powered campaign project developed as part of the Skillovilla training program.

The project demonstrates how structured AI prompting, visual storytelling, and workflow automation can work together to create a campaign system for the AI Career Accelerator program.

The target audience is final-year engineering students preparing for internships and placements.

## Project Objectives

The project focuses on three key areas:

1. **AI-Powered Campaign Messaging:** Develop structured messaging based on student challenges, career uncertainties, skill gaps, and motivations.
2. **Visual AI Storytelling:** Create a five-scene advertising narrative that communicates the student's journey from uncertainty to career preparation.
3. **Lead Handling Automation:** Design an n8n workflow to classify student interest and prepare appropriate responses.

## Project Components

### 1. AI Prompting System

Developed a structured prompting approach to generate campaign messaging for the AI Career Accelerator.

Key areas:
- Student audience understanding
- Prompt framework development
- Prompt chaining
- Meta-prompting
- Iteration and refinement
- Final campaign messaging

### 2. Visual AI System

Created a five-scene visual narrative for a cinematic advertising campaign.

| Scene | Purpose |
|---|---|
| Scene 1 | Problem |
| Scene 2 | Escalation |
| Scene 3 | Solution |
| Scene 4 | Transformation |
| Scene 5 | Call to Action |

### 3. n8n Lead Handling Automation

Designed an n8n workflow named **AI Career Accelerator Lead Handling**.

The workflow includes:
- Receiving student lead information
- Preparing student data
- Storing lead information in Google Sheets
- Classifying leads into three interest categories
- Preparing category-specific responses
- Logging actions in Google Sheets

**Lead categories:**
- Highly Interested
- Exploring
- Just Curious

## Workflow Architecture

The automation follows this general sequence:

`Receive Lead → Prepare Student Data → Google Sheets → Classify Interest → Prepare Response → Log Action`

The workflow export is included in this repository for reference.
